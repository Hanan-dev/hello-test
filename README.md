## Run the news feed

1. Create a NewsAPI key at [newsapi.org](https://newsapi.org/).
2. Copy `.env.example` to `.env` and set `NEWSAPI_KEY` to your key.
3. Start the local app with `python3 server.py`.
4. Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

The local server keeps the API key out of browser code and sends requests to NewsAPI's Top Headlines endpoint. The app supports country, topic, keyword search, sorting, locally saved stories, and a personalized feed based on favorite topics. Topic preferences and saved stories are stored in the user's browser; "For you" combines the selected topics, while individual topic filters remain available. NewsAPI plan restrictions apply.
